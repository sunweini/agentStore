# 属地信源白名单构建

## 为什么白名单决定成败

不配白名单，只搜国际大媒体，等于**放弃早期预警**。国际媒体只在事件足够大时才报道——那时舆情已经成型，处置窗口已经关闭。

真实的时间线通常是：

```
属地小媒体/社交平台  →  属地主流媒体  →  行业垂直媒体  →  NGO/律所介入  →  国际大媒体
     第 0-2 天            第 2-7 天         第 1-2 周        第 2-6 周        第 1-3 月
```

白名单的价值就是把监测点前移到第 0-2 天。

---

## 每个国别要覆盖的六类信源

建白名单时按这六类逐一找，缺哪类补哪类：

### 1. 属地主流媒体
当地发行量最大的日报、通讯社、广播电视台网站。覆盖面广，但对涉外企业负面往往有报道尺度。

### 2. 调查报道媒体 / 独立媒体
**这类最重要。** 溃坝、污染、劳资纠纷这类深度负面，最先出自调查报道媒体。它们通常规模小、域名不知名，需要专门找。

找法：搜索该国"investigative journalism"组织名录、看国际调查记者同盟(ICIJ)的当地成员、看其他同类事件是谁最先报的。

### 3. 行业垂直媒体
该国/该区域的行业媒体（矿业、能源、基建）。专业性强，会报道国际媒体不关心的产能、停产、合规细节。

### 4. 法律/司法数据库
当地法院判例库、法律信息研究所（多数英联邦国家有 XXLII 形式的站点）。

**价值极高**：诉讼往往在媒体报道前就已立案，判例库能提前几周甚至几个月发现法律风险。而且是一手材料，不存在转述失真。

### 5. 政府主管部门
矿业部、环保部、劳动部、招投标平台的官网。发布许可、处罚、检查通报、招标结果。

处罚公告是硬信号——比媒体报道更可靠，且直接构成合规风险证据。

### 6. 国际 NGO 与人权/商业伦理机构
人权组织、商业与人权资源中心、专注企业行为的 NGO、参与诉讼的国际律所。

这类机构介入意味着事件**升级到跨境法律动员阶段**，是事件升级的信号。

## 补充：国际层白名单

除各国别白名单外，另配一份**全组通用的国际层白名单**：国际通讯社、全球行业媒体、国际 NGO、关注该区域的智库或专题媒体。

用于捕捉议题外溢——当某个事件从属地媒体外溢到国际媒体，事件重要性要相应上调。

## 可信度分级与标注

不是所有白名单信源都同等可信。清单里要标出这几类：

| 标注 | 含义 | 处置 |
|---|---|---|
| **单一信源** | 某事件只有这一个来源报道，无交叉验证 | 引用前必须交叉验证；写进报告时注明 |
| **AI 生成站点** | 站点自述内容由 AI 撰写 | **禁作独立依据**，只能作为线索去找原始报道 |
| **明显立场** | 与当事方有利益关联，或立场鲜明 | 保留监测，但引用时注明立场 |
| **流亡/境外媒体** | 战乱区常见，是唯一信息源但难核实 | 保留（无替代），标注核实困难 |
| **企业通稿** | 监测主体或关联方自己发的 | 单列，去重后计入正面，不与第三方报道混计 |

这几条要写进交付物的「调度说明」sheet，不能只在脑子里。

## 白名单在清单中的写法

在「目标信源白名单(域名)」列，用分号分隔的裸域名，便于爬虫直接解析：

```
lusakatimes.com; diggers.news; makanday.org; zambialii.org; mines.gov.zm
```

不写 http/www 前缀，不写路径。国际层白名单可以拼在国别白名单后面。

如果某个信源有**专题标签页/RSS**（比如某媒体给某个项目开了专题页），在运营注里写明可直接订阅——这比关键词检索准确得多，应优先使用。

---

## 白名单的维护

白名单会腐化：站点关停、改域名、新的调查媒体出现。建议：

- 每季度复核一次域名可达性
- 每次发生重大事件后，回看**是谁最先报的**——如果不在白名单里，补进去
- 记录每个信源的历史命中量，长期零命中的考虑剔除（但司法/政府类零命中是正常的，不要剔）
