# 单据/表单插件设计要点

- 触发操作:插件挂载的操作与时机(OnLoad 初始化 / AfterDoOperation 操作后联动 / 操作前校验),
  只挂 w1 确认的单一操作,多操作需求由多个子任务承接。
- 控件绑定:要操作的真实控件字段(选项来自元数据 get_form_fields,如 FQty/库存组织),
  读写方向(读源字段 → 算 → 写目标字段)、控件状态(可见/可编辑)变更。
- 拦截方式:校验不通过走硬拦截(抛异常,操作不提交)还是软拦截(仅提示/标记),
  拦截提示文案要写进设计。
- 联动单据:是否读写其他单据(读库存单校验、生成下游单据等),写明目标 FormId、
  写入字段、是否允许跨组织。
- 异常处理骨架:插件异常(元数据/依赖服务不可用)的回滚策略、日志记录、是否通知审批人。
